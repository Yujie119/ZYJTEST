# 子问题二：资源缺口及原因

`analyze_resources.py`读取子问题一已经选定的分区，在同一冻结任务上重算集中需求、独立需求、库存缺口和共享损失，构造实际同型资源匹配，不重新选择分区。

主要结果：

- `资源缺口原因.md`、`库存缺口分析.csv`：分型数量与成因。
- `组内资源分配见证.csv`、`资源峰值证书.json`：96行资源占用分配及峰值下界证据。
- `分组任务明细.csv`、`分组汇总.csv`、`逐箱继承核验.csv`：任务、工作量与逐箱归属。
- `固定资源事件.csv`、`合并复用收益.csv`、`独立配置分析.json`：资源占用与分组附加需求解释。
- `verify_q4.py`：独立于主求解逻辑复算两个子问题及提交表。
- `核验报告.json`、`逐项核验记录.json`：实际执行生成的核验记录。

从项目根目录运行：

```powershell
& 'E:\tool\anaconda3\python.exe' -X utf8 '问题四/子问题二/analyze_resources.py'
& 'E:\tool\anaconda3\python.exe' -X utf8 '问题四/子问题二/verify_q4.py'
```

独立核验覆盖输入指纹、图连通单元、有标签分区穷举、事件扫描峰值、资源无冲突、逐箱继承、遗憾、LP证书及Excel回读。通信物理证书继承第三问，范围已在核验报告中注明。
