# 子问题一：任务分区与独立资源配置

`solve_partition.py`实现固定任务分区、完整枚举、ε约束、MILP/LP核验、原双目标和最小最大遗憾选择，并执行备选快照和偏好敏感性对照。共享数学模块位于上级`q4_core.py`和`q4_checks.py`。

主要结果：

- `问题四_结果提交.xlsx`：官方模板Q4页，2组和3组各自代表合计5行。
- `最终代表方案.json`：选定分区及各组最低配置。
- `完整分区档案.json`、`分区枚举明细.csv`：完整13种分区，保留精确有理数指标。
- `非支配档案.csv`、`epsilon搜索记录.csv`、`MILP与LP核验.json`：前沿、界与求解证据。
- `备选快照比较.json`、`共同均衡上限比较.csv`：第7.4节同口径对照。
- `偏好与类别权重敏感性.json`、`计算资源记录.json`：敏感性与CPU/双GPU使用记录。

从项目根目录运行：

```powershell
& 'E:\tool\anaconda3\python.exe' -X utf8 '问题四/子问题一/solve_partition.py'
```

重新求解后继续运行子问题二及独立核验，以同步资源匹配和审计结果。也可运行上级`solve_q4.py`一次完成两个子问题。
