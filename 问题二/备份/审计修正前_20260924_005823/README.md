# 问题二求解说明

## 运行

```powershell
E:\tool\anaconda3\python.exe -X utf8 solve_q2.py
E:\tool\anaconda3\python.exe -X utf8 report_q2.py
```

`solve_q2.py`继承问题一的DEM航段、巡航高度、载荷—航程、爬升附加能耗和下降能耗口径。程序生成单点、两点和三点候选架次，以区域—物资类别精确覆盖约束选择路线；随后对每组路线调用固定路线资源MILP，联合决定实体无人机、共享电池、开始时刻和同资源先后关系。首批保障货箱通过“每个首批类别选择一个按时路线”的约束单独处理，医疗物资使用硬截止时间。

候选路线选择包含目标权衡锚点、随机权重和自适应ε情景；可行方案按四目标进行非支配过滤，并在统一归一化尺度下以档案内最小最大遗憾选择代表方案。独立核验器重新计算每条航段的水平能耗和爬升能耗，检查载荷、返航SOC、硬时限、货箱覆盖、无人机区间和电池任务—充电区间。

候选能耗批量核验在两张RTX 3080 Ti上并行执行，路线MILP使用8个并行任务、每个任务1个求解线程，以避免HiGHS线程过度订阅。`计算资源记录.json`保存实际设备与核验误差。

## 结果范围

结果是给定候选路线库和计算预算下的近似非支配方案。它不等同于完整多点路线空间的全局最优证明。最终提交表只填入一套通过独立核验的代表方案；完整架次、逐箱、资源事件和时限核验分别保存在`子问题二`目录。
