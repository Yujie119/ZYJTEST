结果文件是 `best_plan.json`，与 `C_plan.json`内容相同。全部28条候选身份固定，其箱组、机型、访问顺序、能耗与持续时间不变；具体无人机、电池、开始时刻和资源先后开放。采用原 `q2_joint.JointModel`，没有改生产源码、物理参数或原始数据。

第一阶段C上限7567.094096939377，L上限取前序已验证可行见证70.64808661848737；最小化L取得0，因L非负可认证该范围内L最优。第二阶段保留第一阶段可行C上限并用 `L<=1e-7`作为数值零容差，最小化C。其求解器上下界均7264.627910441112，与解码事件重算C仅差约1.62e-10秒。认证范围是**同一28候选下先L后C的词典序子问题**；不证明允许换箱组/路线后的全问题最优，也不证明放宽L后C仍最优。

相对正式方案，N/E完全相同，C减少302.466186498427秒，L由200.565886509374降至0，故严格支配原方案。若用于最终发布，应与主搜索新方案合并并重评共同遗憾，不能仅替换原报告中个别单项指标。

`L_verification.json`、`C_verification.json`分别保存生产核验器结果及完全不导入q2模块的独立原始工作簿/GeoTIFF核算，各426项全部通过。独立几何用像元矩形相交，GeoTIFF PixelIsPoint采用半像元边缘转换。`search_config.json`保存输入来源SHA256，`*_solver.json`保存完整状态、界、容差和耗时，`search_summary.json`保存阶段汇总。每个目标最多120秒，实际两阶段总墙钟约21秒。
